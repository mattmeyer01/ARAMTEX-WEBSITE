# Pomysły na filmy YouTube

Rejestr pomysłów wysłanych do zespołu. Agent YouTube dopisuje tu każdy wysłany pomysł,
a przy kolejnym uruchomieniu sprawdza odpowiedzi zespołu i aktualizuje status.

Statusy: **wysłany** → **tak** (zespół nagrywa; agent przygotowuje pełny scenariusz) / **nie** (nie proponujemy ponownie) / **później**.

|---|---|---|---|---|
